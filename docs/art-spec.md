# 아트 명세서 (캐릭터 · 배경)

외주 작가에게 보내는 견적·작업 요청서이자, AI로 생성할 때의 기준이다. 아이콘(숙련, 무기 종류, 효과, 행동)은 무료 아이콘 세트로 따로 해결하므로 이 문서에서 다루지 않는다.

수치와 목록은 `data/*.json` 기준(2026-10-12)이다. 적이나 모집 유닛이 늘면 이 문서도 고친다.

## 게임 소개 (작가용)

Triangle은 용병단을 꾸려 원정을 나가는 싱글플레이 RPG다. 플레이어는 대원을 모집하고 장비를 입히고, 대원마다 "조건 → 행동" 전술을 짜 둔다. 전투는 자동으로 진행되고 플레이어는 지켜본다.

- 분위기: 어두운 중세 판타지. 이름 없는 용병, 도적, 탈영병, 되살아난 망자, 이단 교단. 영웅담보다는 생존기에 가깝다. 잔혹 묘사(피, 절단)는 최소로 한다.
- 지역: 근교 숲(초보) → 버려진 요새(보통, 영구 사망) → 재의 왕도(어려움, 망자와 교단).
- 참고 분위기: Battle Brothers, Darkest Dungeon, Stoneshard. 분위기만 참고하고 그림을 베끼지 않는다.

## 화면 방향: 초상화 카드

움직이는 전신 스프라이트 대신, 유닛을 **반신 초상화 카드**로 보여 준다. 공격, 피격, 쓰러짐은 코드에서 카드를 흔들고, 번쩍이고, 기울이고, 숫자를 띄워서 연출한다. 그래서 유닛마다 그림이 **한 장**이면 된다.

- 해상도 1280×720. 전투 화면에는 아군 최대 5명과 적 최대 4명, 소환된 정령이 함께 선다.
- 카드는 화면에서 약 96×120px(전투 중)에서 256×320px(대원 정보, 모집 화면)까지 크기를 바꿔 쓴다. 작게 줄여도 누구인지 알아볼 수 있어야 한다.
- 팀 구분(아군 파랑, 적 빨강)과 카드 테두리는 코드에서 그린다. 그림에는 테두리, 글자, 팀 색을 넣지 않는다.

## 화풍 기준

모든 그림이 한 사람이 그린 것처럼 보여야 한다. 이 항목은 1차 시험 그림(아래 "작업 순서")으로 확정하고, 확정한 그림을 이후 작업의 기준으로 삼는다.

| 항목 | 기준 |
|---|---|
| 기법 | 반실사 채색 일러스트(페인터리). 픽셀아트와 애니메이션풍은 쓰지 않는다 |
| 구도 | 허리 위 반신, 3/4 측면. **모두 화면 오른쪽을 본다**(적은 코드에서 좌우를 뒤집는다. 좌우가 바뀌면 어색한 문장이나 글자는 넣지 않는다) |
| 빛 | 왼쪽 위에서 오는 빛 하나. 배경 쪽은 어둡게 떨어진다 |
| 색 | 채도 낮은 흙색, 철색, 가죽색이 기본. 강한 색은 마법(화염 주황, 냉기 청백, 전기 보라)과 교단(검정과 금)에만 쓴다 |
| 배경 | 투명. 바닥 그림자나 배경 그림 없이 인물만 그린다 |
| 실루엣 | 작게 줄여도 무기와 머리 모양이 읽히도록 실루엣을 또렷하게 한다 |
| UI 배경색 | 게임 UI는 거의 검정에 가까운 남색(`#14161C`)이다. 이 위에 놓였을 때 묻히지 않는지 확인한다 |

## 작업 순서

1. **화풍 시험 (3장)**: `ally_aldric`, `enemy_bandit`, `enemy_dead_infantry`. 사람, 평범한 적, 괴물을 한 장씩 받아 화풍을 확정한다. 작가를 여럿 비교할 때도 이 3장으로 견적을 받는다.
2. **초보 지역까지 (10장)**: 아군 초상화 나머지 중 6장(남녀 3명씩), `enemy_dog`, `enemy_poacher`, `enemy_poacher_archer`, `bg_outskirts_forest`. 이것만으로 처음 30분 플레이가 그림으로 채워진다.
3. **나머지 전부**: 남은 아군, 적, 정령, 배경.
4. **스팀 대표 이미지**: 화풍이 확정된 뒤, 출시 페이지를 열기 전에.

## 납품 규격

- 초상화: PNG 32비트(투명 배경), **1024×1280px**(4:5). 눈높이는 위에서 약 35% 위치, 머리 위 여백은 약 8%로 모든 초상화를 맞춘다. 카드에서 같은 위치에 얼굴이 오게 하기 위해서다.
- 배경: PNG, **2560×1440px**(16:9).
- 원본: 레이어가 살아 있는 PSD(또는 작가 도구의 원본 파일)를 함께 받는다.
- 파일 이름: 위 표의 `파일` 이름 그대로(`enemy_bandit.png`). 게임 데이터와 연결하는 키로 쓴다.
- 저장 위치: `src/Triangle.Desktop/Art/portraits/`, `src/Triangle.Desktop/Art/backgrounds/`. 원본 PSD는 용량이 크니 저장소 밖에 보관한다.

## 계약 시 확인할 것

- **상업적 이용**: 판매하는 게임과 그 홍보물(스토어 페이지, 트레일러, SNS)에 써도 되는지.
- **수정 권리**: 색 조정, 자르기, 좌우 반전, 효과 덧칠을 직접 해도 되는지.
- **독점**: 같은 그림을 다른 곳에 팔거나 재사용하지 않는지.
- **크레딧**: 게임 안 크레딧 화면과 스토어 페이지에 이름을 어떻게 표기할지.
- **AI 사용 여부**: 작가가 작업에 AI를 썼는지 명시하게 한다. 스팀은 AI 생성 콘텐츠를 신고해야 하고, 쓰지 않았다면 그것도 홍보에 쓸 수 있다.
- **수정 횟수와 단계**: 스케치 확인 → 채색 확인 → 최종처럼 단계마다 확인받는 횟수를 정한다.

## AI로 생성할 때

AI로 만들 경우에도 위의 화풍 기준과 납품 규격을 그대로 지킨다. 통일감을 위해 다음을 지킨다.

- 1단계 시험 3장을 먼저 만들고, 마음에 드는 결과를 **스타일 참조 이미지로 고정**해서 이후 모든 그림에 넣는다.
- 지시문은 아래 틀을 공통으로 쓰고 `{인물}` 부분만 바꾼다.
- 결과물은 손으로 다듬는다. 손가락, 무기 잡은 손, 갑옷 이음새처럼 AI가 자주 틀리는 곳을 확인하고 배경을 지워 투명하게 만든다.
- 스팀 등록 시 AI 사용을 신고한다.

```
Half-body portrait of {인물}, three-quarter view facing right,
dark medieval fantasy mercenary game, semi-realistic painterly style,
muted earthy palette, single light source from upper left, dark falloff,
no background, isolated on transparent background, no text, no frame,
consistent with the style reference
```

`{인물}` 예시:
- 알드릭: `a man in his 30s with short brown hair, steady trustworthy face, wearing a worn padded gambeson and travel cloak, no weapon`
- 도적: `a forest bandit in tattered leather armor and a hood, holding a rusty short sword`
- 망자 보병: `an undead skeleton soldier in rusted royal plate armor, faint glow inside the helmet visor, holding a notched sword`
