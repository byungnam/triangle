# 리라이트 메모

레거시 분석에서 나온 결론이다. 무엇을 가져가고 무엇을 버릴지, 그리고 결정이 필요한 사항을 정리했다.

## 가져갈 것 (검증된 핵심 루프)

1. **유닛 수집과 육성**: 5개 스탯과 포인트 배분.
2. **갬빗 전술**: 우선순위, 조건(+값), 행동 목록. 처음으로 참이 되는 규칙을 실행한다.
3. **ATB 행동 순서**: `TIME / (직업계수 × speed)`만큼 타이머가 쌓이고, 타이머가 가장 낮은 유닛이 행동한다.
4. **방어력 경감**: `피해 / (1 + 0.02 × def)`.
5. **팀 편성 → NPC 팀과 자동 전투**.

## 버릴 것

- 4개 서버로 나뉜 구조. GameServer는 사실상 프록시였다.
- 요청과 응답이 같은 protobuf 메시지 구조, Netty 5 alpha.
- `NextNumber` 테이블과 트리거로 만드는 ID, NPC 테이블 전체 복제.
- 출처가 불분명한 아트 전부.
- `CopyOf*` 파일, BattleServer, 주석 처리된 블록.

## 리라이트 전에 결정할 것

1. **싱글플레이 vs 멀티플레이.** 가장 큰 갈림길이다. 레거시는 온라인이었지만 PvP 없이 NPC 팀과만 싸웠다.
   싱글플레이로 가면 서버, 계정, 프로토콜, DB가 전부 사라지고 로컬 저장으로 충분하다.
2. **타깃 플랫폼.** 데스크톱만 할지, 모바일(Android/iOS)까지 할지. MonoGame은 둘 다 지원한다.
3. **전투 표현.** 텍스트 로그만 보여줄지, 아레나 위에 스프라이트와 애니메이션을 올릴지. 어느 쪽이든 전투 시뮬레이션은 결정적(시드 고정)으로 만들고, **이벤트 로그를 출력**하게 해서 표현 계층과 분리하는 것을 권장한다.
4. ~~**전술 대상 지정.**~~ → 결정(2026-10-02): 전술에는 대상 칸을 두지 않는다. 대신 스킬마다 대상 우선순위 규칙을 정의하고, 전위/후위 진형과 함께 동작하게 한다.
5. ~~**직업과 스킬 목록.**~~ → 결정(2026-10-02): 직업을 없애고 Albion Online식으로 육성한다. 장착한 장비 계열로 싸워 숙련을 올리고, 숙련 포인트로 그 계열의 패시브 트리를 배운다. 행동은 무기 계열과 패시브 레벨로 열린다. 수치는 새로 밸런싱한다(현재 임시).
6. **미구현 시스템의 범위.** 결정된 것: 진형(전위/후위), 스킬 트리, 효과(버프/디버프/지속 피해·회복, MP 회복)는 넣는다. 경험치/레벨업은 장비 숙련으로 대체한다. 부활은 넣지 않는다(사망을 가장 큰 페널티로). 아이템, 전장 난이도는 미정.
7. ~~**테마.**~~ → 결정(2026-10-03): 고대 로마/포에니 전쟁 무드를 버리고 딥다크 중세 판타지로 간다.
8. ~~**데이터 관리.**~~ → 결정(2026-10-02): JSON 데이터 파일 + 별도 편집기 도구(UnitManager 대체). 편집기의 형태는 미정.
